# Security

Do not open a public issue containing credentials, private repository content,
personal data, or an exploit that would put users at immediate risk.

Report sensitive findings through GitHub's private vulnerability reporting for
this repository. Include the affected version, exact rule or installer step,
impact, reproduction details, and a safe remediation when known.

This repository contains instructions and static assets; it does not collect
telemetry, execute a hosted service, or require secrets. Installation must never
modify Codex authentication or print credential values.
