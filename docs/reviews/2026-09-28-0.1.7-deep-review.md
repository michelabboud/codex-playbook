## Minor findings — all fixed

1. **"The platform skill gives the command" pointed at nothing** for "no process
   uses this directory" (inherited from the source). Each platform skill now
   has a directory row: `lsof +D` and `fuser -v` on Linux (verified on this
   machine against a process sitting in a probe directory), `lsof +D` on macOS,
   and on Windows Sysinternals `handle.exe` or Resource Monitor, or an honest
   "not run". The source edition takes the same fix.
2. **The escalated-retry ban forbade Codex's own way of asking.** One escalated
   request, with the refusal in its justification, is now allowed — never
   under the `never` policy, never after a decline — in rule 10.1 and the
   router; the quarantine skill notes its move may need it.
3. Two "sixteen skills" left in the map and the parity matrix.
4. Nineteen untested clauses (refusal routes, 13.3's data-safety clauses, the
   foreign-marker clause, economy details) — each now asserted, and all 53 new
   assertions shown to fail when their phrase is removed.
5. The "tier never drops" sentence now names the economy exception; the
   roster's binding section names the economy configuration.
